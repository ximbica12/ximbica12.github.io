# YouTube J7 Native

Native non-root build for Samsung Galaxy J7 Prime / Android 8 / ARMv7.

## Base
- Stock YouTube 20.05.46
- anddea stable patches v4.2.0
- armeabi-v7a only
- GmsCore/MicroG support

## Minimal patch set
- Hide ads
- SponsorBlock
- GmsCore support
- Spoof video streams
- Disable QUIC protocol
- Video playback controls
- Background playback
- Return YouTube Dislike
- Sanitize sharing links
- Alternate Revancify Red launcher icon

The build intentionally avoids the large default patch set to reduce moving parts and playback regressions on Android 8.
