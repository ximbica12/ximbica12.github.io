# Third-party components

This prototype uses:
- Mozilla GeckoView 154.0.20260824154132.
- uBlock Origin 1.75.0 by Raymond Hill and contributors (GPL-3.0).
- SponsorBlock 6.1.7 by Ajay Ramachandran and contributors (GPL-3.0).

The GitHub Actions build downloads the official Firefox release packages for uBlock Origin
and SponsorBlock and bundles them as GeckoView built-in WebExtensions.
