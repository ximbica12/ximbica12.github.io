Política de Privacidade

Esta Política de Privacidade descreve como o TubeLite J7 trata informações quando você usa o aplicativo e, em especial, quando escolhe conectar uma Conta Google.

1. Conta Google e autenticação

O TubeLite J7 usa o fluxo oficial OAuth 2.0 do Google. O aplicativo não coleta, não recebe e não armazena sua senha do Google. A autenticação, inclusive senha e autenticação em dois fatores, ocorre nas interfaces controladas pelo Google.

Quando disponível e autorizado pelo usuário, o aplicativo pode receber identificadores de conta exibidos pelo Google, como nome ou endereço de e-mail, para identificar localmente qual conta está conectada.

2. Dados do YouTube acessados

Quando você conecta sua Conta Google, o TubeLite J7 solicita somente as permissões necessárias aos recursos de conta. O escopo principal usado é https://www.googleapis.com/auth/youtube.readonly.

Dependendo do recurso utilizado, esse acesso pode incluir dados de leitura associados à sua conta do YouTube, como informações do canal, inscrições, playlists e outros dados disponibilizados pela YouTube Data API dentro do escopo autorizado.

O TubeLite J7 não usa esse escopo para publicar, editar ou excluir vídeos e não solicita sua senha do Google.

3. Como esses dados são usados

Dados obtidos por meio das APIs do Google são usados apenas para fornecer funcionalidades que o usuário solicitou dentro do aplicativo, como mostrar a conta conectada e carregar dados de leitura do YouTube vinculados a essa conta.

Esses dados não são vendidos e não são usados para publicidade personalizada, criação de perfis publicitários ou análise destinada a terceiros.

4. Armazenamento e tokens

Credenciais OAuth e tokens necessários à sessão são tratados no dispositivo e/ou pelos componentes oficiais de autenticação do Google. O TubeLite J7 não opera um servidor próprio destinado a coletar senhas do Google.

O aplicativo pode manter localmente informações necessárias à experiência, como conta selecionada, preferências, histórico local, inscrições locais, playlists locais e cache. Esses dados podem ser removidos ao limpar os dados do aplicativo ou desinstalá-lo.

5. Compartilhamento

O TubeLite J7 não vende dados do usuário do Google. Tokens OAuth e dados privados obtidos pela YouTube Data API não devem ser enviados a serviços opcionais de terceiros que não sejam necessários à autorização ou à chamada da API do Google.

O aplicativo pode se comunicar com serviços externos necessários a outros recursos do próprio cliente, como infraestrutura do YouTube/Google ou serviços opcionais presentes na base LibreTube. Esses serviços possuem políticas próprias. O uso desses recursos não autoriza o TubeLite J7 a fornecer a eles a senha da Conta Google.

6. Revogação e exclusão

Você pode desconectar sua Conta Google dentro do aplicativo quando essa opção estiver disponível e também pode revogar a autorização a qualquer momento nas configurações de segurança da sua Conta Google.

Dados armazenados localmente podem ser apagados por meio das configurações do Android ao limpar os dados do aplicativo ou ao desinstalar o TubeLite J7.

7. Google API Services User Data Policy

O uso e a transferência, pelo TubeLite J7, de informações recebidas das APIs do Google obedecerão à Google API Services User Data Policy, incluindo os requisitos de Limited Use.

8. Segurança

O projeto procura limitar o acesso aos dados ao mínimo necessário. Nenhum sistema é totalmente isento de risco; por isso, permissões desnecessárias não devem ser solicitadas e o usuário pode revogar o acesso quando desejar.

9. Alterações nesta política

Esta política pode ser atualizada quando os recursos do aplicativo ou o uso das APIs mudarem. A data de atualização será alterada nesta página.

10. Contato e código-fonte

O projeto é mantido por ximbica12. Questões técnicas ou de privacidade podem ser encaminhadas pelo repositório do projeto no GitHub ou pelo endereço de suporte exibido na tela de consentimento OAuth do Google.
